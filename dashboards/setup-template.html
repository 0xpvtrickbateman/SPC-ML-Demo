Set up the AttainX dashboard

This helper creates the dashboard import file for your catalog and schema. It runs locally and does not connect to Databricks.

1. Confirm the demo destination

In Databricks Catalog Explorer, open ml_statistical_process_controls → demo_schema. Verify that you can create and update demo tables there. The notebook and this import file use the same destination by default. This default-storage catalog requires serverless compute for direct access: use serverless notebook compute and a serverless SQL warehouse for this catalog, and verify availability and permissions. This does not apply to every catalog.

If your authorized destination differs, change both fields here and copy the matching notebook setting below. The helper only generates a local file.

2. Run the updated notebook

In Databricks, click Workspace → open your demo folder → its ⋮ menu → Import → choose File → select SPC_ML_Demo.py from this repository's notebooks folder → Import. Use a new name if you want to preserve your old notebook.

Open it. In Cell 1, confirm the OUTPUT_SCHEMA setting is:

OUTPUT_SCHEMA = "ml_statistical_process_controls.demo_schema"
UC_MODEL_NAME = ""

Select your Python notebook compute at the top → click Run all. Confirm every code cell finishes successfully. The SQL warehouse is for the dashboard; use your working Python compute for the notebook.

Return to Catalog → your catalog → your schema and refresh. Check the notebook’s output table manifest, including demo_drift_inputs, demo_drift_performance, demo_drift_daily, and review_queue.

3. Import the dashboard

In Databricks, click Dashboards → the menu beside Create dashboard → Import dashboard from file → select the downloaded AttainX_SPC_Demo.lvdash.json → Import.

In the dashboard editor's warehouse selector, choose your SQL warehouse. If you need its name, click SQL Warehouses in the left sidebar; use an existing warehouse you can access.

Click Data, select each dataset and click Run. This checks the imported queries against your workspace. Return to Canvas and refresh the dashboard. Publishing is optional for sharing; the draft is enough for your rehearsal.

Local checks cover calculations, SQL against local tables, and the companion preview. Import, query execution and native widget rendering still need verification in your Databricks workspace.

4. Show the drift story

Keep the queue filter at Intake A. Open Overview, then Detect drift. Read the latest data dates, matched actuals and model identity before comparing current error to the reference. These are synthetic USCIS-related application volumes, not agency performance data.

Open Drift exercise. Error rises above the reference-based threshold for two windows, leading to Review for retraining. Then open Review and retrain to explain the human decision and rollback.

In the notebook's Cell 22 view, use the same four-part walkthrough. Open the local rehearsal preview.
